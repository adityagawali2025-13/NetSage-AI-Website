NETSAGE AI WEBSITE

1. Extract the ZIP.
2. Double-click index.html to explore the website without a server.
3. For the ORIGINAL Python diagnostics engine (recommended), install Python 3 and run:
   python server.py
4. Open http://localhost:8000 in your browser.

The Case Explorer and Human Review views use the uploaded project CSVs.
When launched directly as a file, diagnostics run an equivalent browser rule checker.
When launched with server.py, diagnostics use the uploaded netsage_checker.py directly.
This website does not make AI API calls or connect to Cisco Packet Tracer.
