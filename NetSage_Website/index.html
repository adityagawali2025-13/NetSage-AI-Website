METHOD & RESPONSIBILITY

Evidence before action.

NetSage combines Cisco-style lab observations, structured diagnosis, deterministic checks, and mandatory human review.

01

Collect evidence

Record symptoms, topology notes and relevant Cisco show-command output.

02

Propose diagnosis

Use the supplied structured AI prompt in an external AI assistant; require uncertainty and cited case evidence.

03

Run checks

Validate structured network data using the Python rule checker, independently of AI suggestions.

04

Human review

Accept, edit or reject the proposed diagnosis based on evidence and intended network policy.

05

Fix & verify

Apply the reviewed correction in Packet Tracer and repeat diagnostic commands and connectivity tests.

About this demonstration

This website presents the uploaded 30-case NetSage project dataset. It does not connect to Cisco Packet Tracer, run an AI model, apply networking fixes, or claim to verify recovery automatically. The AI prompt is available in the original project files; the diagnostics panel uses deterministic rules.
